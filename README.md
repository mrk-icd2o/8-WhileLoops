# Lab 8 - Years to Goal

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

The main reason to use a while loop is to repeat code an unknown number of times. In this lab you don't know how many years it will take, so a for loop isn't a good fit.

`sketch.js` already has starter code (two input boxes and a button). Complete the `calculateGoal()` function:

- Calculate how many years it will take to go from the **Starting Amount** to the **Target Goal**, at 5% interest per year.

- Use a while loop to perform this calculation.

- Display the number of years, and the final balance, below the button.

Challenge:

- Add an input box so the user can choose the interest rate.

- What happens if the user enters 0 for the starting amount? Prevent the program from freezing.
